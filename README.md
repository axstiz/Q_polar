# Q-polar

Интерактивный сборник стихов в виде **портативной игровой консоли**.

Главная страница — это приставка: на её экране — интерактивная SVG-схема сборника, а все элементы управления — игровые кнопки и крестовина консоли. Кнопки отвечают за навигацию по дереву стихов, открытие текста, паузу/воспроизведение озвучки и переключение видов.

## Структура проекта

```text
/
├── public/
│   ├── favicon.svg           # Favicon (стилизованная Q)
│   ├── favicon.ico           # Fallback favicon
│   ├── console-base.png      # Корпус приставки
│   ├── приставка/            # PNG-кнопки и экран консоли
│   ├── QRs/                  # QR-коды со ссылками на сайт и TG-канал
│   └── audio/                # Озвучка стихов (имя = слаг стиха, напр. intro.mp3)
├── src/
│   ├── components/
│   │   ├── GameConsole.astro  # Приставка: управление, навигация, аудиоплеер, QR-дисплей
│   │   ├── FlowDiagram.astro  # Интерактивная SVG-схема сборника (экран консоли)
│   │   └── holograms/         # Перекрёстные CSS/SVG анимации для каждого блока
│   ├── data/
│   │   └── poems.ts          # Данные стихов (ТЕКСТЫ правятся тут, поле lines) + граф навигации
│   ├── layouts/
│   │   └── PoemLayout.astro  # Шаблон страницы стиха
│   ├── pages/
│   │   ├── index.astro       # Главная — приставка с фоновым паттерном-волной
│   │   └── poems/            # 11 страниц стихов (+ алиас klyatva)
│   └── styles/
│       └── global.css        # Глобальные стили + CSS-анимации
├── texts/                    # Исходные тексты стихов (.txt)
├── astro.config.mjs          # Конфигурация Astro
└── package.json
```

> Тексты стихов правятся в `src/data/poems.ts` (поле `lines: string[]`; пустая строка = пауза). Файлы `texts/*.txt` — исходники, в сборку не подключены.

## Граф навигации (на экране приставки)

Схема основана на двуветвящемся графе:

```
Intro → Coal → ┬→ Settings → Blaze ┬→ Blue screen → Collapse
               │                   └→ klyatva-exo
               └→ Face id  → tRace → Lastick     ──→ Collapse
```

## Приставка и управление

- **Крестовина (стрелки)** — перемещение по дереву стихов. Работают и клавиатурные стрелки.
- **Большая кнопка** — открыть выбранный стих.
- **"Enter" (горизонтальная)** — расширенный вид стихотворения внутри экрана.
- **Маленькие кнопки** — пауза и воспроизведение озвучки.
- **Сенсорный экран** — на экран консоли можно нажимать напрямую.
- Озвучка стихов (mp3 из `public/audio`) проигрывается во встроенном аудиоплеере приставки.

## Аудиоплеер

- Прогресс-бар (кликабельный) и регулировка громкости.
- **Визуализатор-волна** на базе FFT-анализа (Web Audio API): реагирует на бит; в покое — чаша-парабола.
- Кнопки паузы/воспроизведения на корпусе консоли.

## Ссылки и QR

- На экране отображаются **кликабельные QR-коды** со ссылками на сайт Q-polar и Telegram-канал.
- QR-дисплей открывается из режима схемы; из расширенного вида стиха нужно выйти, чтобы увидеть QR.

## Фон

На фоне главной страницы — **пунктирные контуры-волны**, повторяющие силуэт приставки в акцентных цветах; зазор между штрихами растёт с удалением от корпуса.

## Технологии

- **Astro** — статический генератор сайтов
- **HTML + CSS + vanilla JS** — без фреймворков
- **SVG** — интерактивная схема и фоновый паттерн
- **Canvas + Web Audio API (FFT)** — визуализатор сигнала в плеере
- **CSS @keyframes** — цикличные анимации для каждого блока

## Анимации

Каждый блок на схеме имеет свою уникальную CSS-анимацию при наведении.
