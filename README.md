# Q-polar

Интерактивный сборник стихов с навигацией по ветвящейся схеме.

Сайт представляет собой SVG-диаграмму, где каждый блок — это стих. Наведи на блок, чтобы увидеть превью; нажми, чтобы перейти к тексту.

## Структура проекта

```text
/
├── public/
│   ├── favicon.svg           # Favicon (стилизованная Q)
│   ├── favicon.ico           # Fallback favicon
│   ├── console-base.png      # Корпус приставки
│   ├── приставка/            # Кнопки и экран приставки (PNG)
│   ├── QRs/                  # QR-коды (Q-polar и TG-канал)
│   └── audio/                # Аудиотреки (имя = слаг стиха, напр. intro.mp3)
├── src/
│   ├── components/
│   │   ├── GameConsole.astro  # Интерактивная консоль (кнопки, навигация, звук,
│   │   │                      # аудиоплеер со спектр-волной и QR-дисплеем)
│   │   ├── FlowDiagram.astro  # Интерактивная SVG-схема сборника
│   │   └── holograms/         # Перекрёстные CSS/SVG анимации для каждого блока
│   ├── data/
│   │   └── poems.ts          # Данные стихов (ТЕКСТЫ правятся тут, поле lines) + граф навигации
│   ├── layouts/
│   │   └── PoemLayout.astro  # Шаблон страницы стиха
│   ├── pages/
│   │   ├── index.astro       # Главная — приставка со схемой и фоновым паттерном-волной
│   │   └── poems/            # 11 страниц стихов (+ алиас klyatva)
│   └── styles/
│       └── global.css        # Глобальные стили + CSS-анимации
├── texts/                    # Исходные тексты стихов (.txt)
├── astro.config.mjs          # Конфигурация Astro
└── package.json
```

> Тексты стихов правятся в `src/data/poems.ts` (поле `lines: string[]`; пустая строка = пауза). Файлы `texts/*.txt` — исходники, в сборку не подключены.

## Навигация

Схема основана на двуветвящемся графе:

```
Intro → Coal → ┬→ Settings → Blaze ┬→ Blue screen → Collapse
               │                   └→ klyatva-exo
               └→ Face id  → tRace → Lastick     ──→ Collapse
```

## Приставка (GameConsole)

- Навигация кнопками-стрелками по дереву стихов; большая кнопка — открыть стих, кнопка "Enter" — расширенный вид.
- Аудиоплеер: прогресс-бар, громкость, визуализатор-волна (FFT, отклик на бит; в покое — чаша-парабола).
- QR-дисплей с ссылками на сайт и TG-канал (выход из расширенного вида).
- На фоне страницы — пунктирные контуры-волны вокруг приставки в акцентных цветах, зазор растёт с удалением.

## Команды

| Команда         | Действие                                    |
| :-------------- | :------------------------------------------ |
| `npm install`   | Установка зависимостей                      |
| `npm run dev`   | Запуск dev-сервера на `localhost:4321`      |
| `npm run build` | Сборка в `./dist/`                          |
| `npm run preview` | Предпросмотр собранного сайта             |

## Технологии

- **Astro** — статический генератор сайтов
- **HTML + CSS + vanilla JS** — без фреймворков
- **SVG** — интерактивная диаграмма и фоновый паттерн
- **CSS @keyframes** — цикличные анимации для каждого блока
- **Canvas (Web Audio API)** — визуализатор сигнала в плеере

## Анимации

Каждый блок на схеме имеет свою уникальную CSS-анимацию при наведении.
