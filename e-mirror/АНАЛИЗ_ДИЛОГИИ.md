# e-mirror + Q-polar: анализ дилогии

## Архитектура

| | e-mirror (2025) | Q-polar (2026) |
|---|---|---|
| Форма | Музыкальный альбом (13 треков) | Веб-сборник стихов (9 стихов) |
| Медиум | Аудио + текст | Текст + интерактивная схема (SVG) |
| Герой | icore — субъект **в процессе** распада | icore — субъект **уже разделённый**, помещённый в граф |
| Движение | Хаотичное, метание, циклы | Ветвящееся, детерминированное |
| Финал | Сшивание двух душ (лоскуты) | Схождение обеих веток в Collapse |

e-mirror — хаос до структуры. Q-polar — структура после хаоса.  
**Q-polar начинается ПОСЛЕ лоскутов** — герой уже сшит из двух душ и входит в граф.

---

## Хронология

1. **e-mirror** (13 треков) — вся предыстория: хаос → метание → горение → попытка перерождения (FUEL) → кульминация (VAMPIRE_13: «кем я стал?») → сшивание двух душ (лоскуты)
2. **Q-polar** (9 стихов) — начинается **после** сшивания двух душ в «лоскуты». Две души уже разделены и расходятся по ветвям бинарного графа → проходят свои пути → сходятся в Collapse

---

## Ключевая находка: форма графа = символ из потоlock

**Символ `><>` из трека «потоlock» — буквальная форма графа Q-polar.**

Граф:
```
         Settings → Blaze → Blue screen   ← спинной край тела
        ↗                                ↘
Intro → Coal                              Collapse
        ↘                                ↗
         Face id → tRase → Lastick       ← брюшной край тела
```

- **Intro и Coal** — голова/начало рыбы
- **Расходящиеся ветки** — верхний и нижний контур тела
- **Схождение в Collapse** — хвост/рот (в зависимости от направления)

Но при этом:

### Intro = хвостовой плавник (caudal fin)

Точки Intro (intro-dots + intro-dots-mirror) расположены **веером**: X: 89→319, Y: 387→548 (верх) и 788→628 (низ).  
Два зеркальных веера — **верхняя и нижняя лопасти хвоста**.  
Анимация `dotFlowRight` — **удар хвоста** при плавании (рывки точек вправо).

### Полная анатомия рыбы

```
         Settings → Blaze → Blue screen    ← спинной край
        ↗                                ↘
[ХВОСТ] Coal                              Collapse [ГОЛОВА?]
        ↘                                ↗
         Face id → tRase → Lastick       ← брюшной край
```

Intro → Coal — хвост + основание хвоста.  
Две ветки — тело рыбы (верх/низ).  
Collapse — голова (если рыба плывёт справа налево) или хвост (если слева направо).

## Анимации веток

### Верхняя ветка (спинной край) — огонь как агрессия вовне

| Блок | Анимация | Характер |
|---|---|---|
| Settings | Красные + фиолетовые пульсирующие частицы | Активное излучение |
| Blaze | Языки пламени (scale flicker + drop-shadow) | Физическое горение |
| Blue screen | Трещины (crackGrow), глитч (RGB-сдвиг + translate) | Разрушение системы, визуальный шум |

### Нижняя ветка (брюшной край) — пассивное угасание

| Блок | Анимация | Характер |
|---|---|---|
| Face id | Сканирующая линия, сетка точек, замок | Холодное наблюдение, распознавание |
| tRase | Обводка контура (stroke-dashoffset), капля крови | Хирургично, истекание |
| Lastick | **Hover-анимация не доделана** | Пустота |

Верхняя: **субъект действия** («я горю»). Нижняя: **объект процесса** («меня стирают»).

---

## Текстовая маркировка двух душ

Несмотря на визуальную симметрию, тексты чётко различают ветки:

- **Верхняя (Settings → Blaze → Blue screen):** активное горение, огонь вовне. «Я всё поджигал», «Спасибо всем сукам со спичками / Я горю». Даже крах — «Музей горения» — огонь был.

- **Нижняя (Face id → tRase → Lastick):** пассивное угасание, стирание изнутри. «Страшно от страха исчезнуть», «Приковав себя цепью к поддереву», «Лица стирают меня из себя».

Одна душа выжигает себя вовне, другая растворяется внутри. Обе приходят к Collapse разными маршрутами.

---

## Ключевые переклички

- **«в глазах двоится» (e-mirror, трек 6)** — точка бифуркации внутри альбома, где один путь становится двумя.
- **«метроном, зажигалка, фото» → Face id** — «Exitcode: глаза, шум» из e-mirror переходит в Face id в Q-polar.
- **FUEL → Blaze** — попытка перерождения через огонь (альбом) → горение как терминальная стадия (сборник).
- **«лоскуты» → Collapse** — сшивание двух душ → схлопывание в ноль.
- **«падаю вверх» (потоlock) → «эта гонка — падение вверх» (tRase)** — прямая метафорическая связь.

## Система псевдонимов

- **icore** — голос, эмоция, хаос. Поэт/музыкант.
- **axstiz** — форма, структура, код. Разработчик.

«Акстись» (крещение, инициация).  
icore — техника/боль, axstiz — форма/ритуал. Два полюса инь-янь.

---

## Центральная метафора: падение вверх

Введена в **потоlock** (e-mirror, трек 12): «Но я падаю вверх / Лечу головой вниз / И как щука ><> рассекаю поток пескарей».  
Подхвачена в **tRase** (Q-polar): «Эта гонка — падение вверх».

Развитие, которое ощущается как падение. Движение против гравитации.
